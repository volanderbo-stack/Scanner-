# Scanner — розпізнавання тексту з фото й скріншотів

Скрипт бере фото з камери або скріншот і повертає текст українською та англійською
зі збереженими рядками й абзацами. Працює повністю офлайн і безкоштовно
(Tesseract 5 + OpenCV).

```
python ocr.py photo.jpg          # одна картинка
python ocr.py папка/             # усі картинки в папці
python ocr.py photo.heic -v      # показати, що зроблено з картинкою
```

Текст друкується в консоль і зберігається поруч: `photo.jpg` → `photo.txt`.

## Встановлення на Windows

### 1. Python
Python 3.10 або новіший з [python.org](https://www.python.org/downloads/).
Під час встановлення познач **Add Python to PATH**.

### 2. Tesseract OCR
1. Завантаж інсталятор Tesseract 5 для Windows (збірка UB Mannheim):
   <https://github.com/UB-Mannheim/tesseract/wiki> → `tesseract-ocr-w64-setup-5.x.x.exe`.
2. Встанови в стандартну теку `C:\Program Files\Tesseract-OCR`.
   На кроці *Additional language data* можна нічого не відмічати — моделі поставимо кращі.
3. Перевір у новому вікні PowerShell:
   ```powershell
   & "C:\Program Files\Tesseract-OCR\tesseract.exe" --version
   ```
   Додавати теку в PATH не обов'язково — `ocr.py` сам знайде її в `Program Files`.

### 3. Моделі `tessdata_best` для української та англійської
Стандартні моделі (`fast`) помітно гірші. Потрібні **best**:

**Варіант А (простіший)** — у теці проєкту:
```powershell
python get_models.py
```
Скрипт завантажить `ukr`, `eng`, `osd` з
[tessdata_best](https://github.com/tesseract-ocr/tessdata_best) у `tessdata_best\`,
і `ocr.py` візьме їх звідти автоматично.

**Варіант Б (вручну)** — завантаж файли
[`ukr.traineddata`](https://github.com/tesseract-ocr/tessdata_best/raw/main/ukr.traineddata),
[`eng.traineddata`](https://github.com/tesseract-ocr/tessdata_best/raw/main/eng.traineddata),
[`osd.traineddata`](https://github.com/tesseract-ocr/tessdata_best/raw/main/osd.traineddata)
і поклади їх у `C:\Program Files\Tesseract-OCR\tessdata\` із заміною
(PowerShell або Провідник — від імені адміністратора).
Перевірка: `& "C:\Program Files\Tesseract-OCR\tesseract.exe" --list-langs` має показати `ukr` і `eng`.

Розмір best-файлу `ukr.traineddata` — приблизно 10,9 МБ (fast — 3,8 МБ), так можна
перевірити, яку версію поставлено.

### 4. Бібліотеки Python
```powershell
cd шлях\до\Scanner-
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Як це працює

1. **Завантаження**: jpg/png/heic/webp; фото повертається за EXIF (фото з телефону часто «лежать боком»).
2. **Тип картинки визначається автоматично.** У скріншота багато однакових сусідніх
   пікселів (рівні заливки, немає шуму сенсора); фото з EXIF камери — завжди фото.
   - **Скріншот** майже не чіпаємо: сірі тони, інверсія для темної теми, збільшення дрібного шрифту.
   - **Фото**: пошук аркуша й виправлення перспективи → сірі тони (+ інверсія, якщо
     текст світлий на темному) → вирівнювання освітлення (ділення на фон, прибирає
     тіні) → масштаб, щоб літери були ~32 px → вирівнювання нахилу.
   - CLAHE, бінаризацію, прибирання шуму й розтягування контрасту перевірено й
     **вимкнено**: на тестах вони не покращують або погіршують результат
     (Tesseract LSTM краще читає сіру картинку, ніж ч/б).
3. **Tesseract** з `tessdata_best`, `--oem 1` (нейромережа LSTM), мови `ukr+eng`.
   Запускається з кількома `--psm` паралельно, береться результат з найвищою
   середньою впевненістю.
4. **Обробка тексту**: склеювання переносів (`сло-` + `во` → `слово`), прибирання
   сміттєвих рядків і сміття на краях рядків, виправлення латинських «двійників» у
   кириличних словах (`i`/`і`, `o`/`о`, `c`/`с`, `3BIT` → `звіт`), дрібні виправлення
   розділових знаків (`--` → `—`, `№`, кома в кінці абзацу → крапка), відновлення
   абзаців за відступами та інтервалами між рядками.

Корисні параметри `ocr.py`:

| Параметр | Що робить |
|---|---|
| `-v` | показати кроки: тип, масштаб, нахил, обраний psm |
| `--type photo` / `--type screenshot` | не визначати тип автоматично |
| `--psm 3,4,6` | які режими сторінки пробувати |
| `--lang ukr` | лише українська (трохи точніше, якщо англійської немає зовсім) |
| `--tessdata ТЕКА` | де лежать `ukr/eng.traineddata` |
| `--debug ТЕКА` | зберегти підготовлену картинку, яку бачить Tesseract |
| `--engine easyocr` | інший рушій (потрібен `pip install easyocr`) |
| `--no-save` | не створювати `.txt` |

## Перевірка якості

У `tests/` лежать 14 картинок і правильний текст до кожної (`.gt.txt`):
скріншоти (чат, дрібний шрифт, темна тема, веб-сторінка, укр+eng) і фото
(сторінка книжки, під кутом, у тіні, екран монітора, чек, лежить боком за EXIF,
темне фото, з нахилом, дрібний текст з розмиттям).

```
python evaluate.py              # CER/WER по кожній картинці
python evaluate.py --diff       # ще й показати розпізнаний текст там, де є помилки
python evaluate.py --ablation   # «до → після» і внесок кожного кроку (~40 хв)
python evaluate.py --engine easyocr   # порівняння з EasyOCR → results_easyocr.md
```

Щоб налаштування не були «підігнані» під 15 картинок, їх перевірено ще на двох
наборах з іншим випадковим шумом/кутом/тінню:
```
python tests/make_tests.py 2 tests_seed2
python tests/make_tests.py 3 tests_seed3
python evaluate.py --tests tests tests_seed2 tests_seed3
```

Результати пишуться в `results.md`, висновки — у [ЗВІТ.md](ЗВІТ.md).

**Додати свої тести:** поклади в `tests/` картинку й файл з тим самим ім'ям і
розширенням `.gt.txt` (UTF-8): рядки як на картинці, абзаци через порожній рядок,
перенесене слово — цілим на першому рядку. Назва `screen_…` — скріншот, інакше — фото.

Тестові фото згенеровані скриптом `tests/make_tests.py` (перспектива, тінь, шум,
муар, стиснення як у месенджері). Вони схожі на справжні, але справжні фото з
телефону зазвичай складніші, тому варто додати кілька своїх.
